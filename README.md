# ATLASE

ATLASE is a fragrance e-commerce platform built with Next.js, Supabase, and a pnpm + Turborepo monorepo architecture. It provides product management, customization, checkout, and admin features for selling fragrances online.

For detailed documentation, see [docs/](./docs/) and the [master plan](./docs/superpowers/plans/phase-1-foundation.md).
