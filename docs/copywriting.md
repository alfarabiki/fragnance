# ATLASE — Copywriting Guidelines

## 1. Language Rules

**Primary language:** Bahasa Indonesia (simple, conversational, no Bahasa baku stiffness)

**Target reader:** Someone who may not know perfume terminology. Write like you're explaining to a friend, not briefing a professional.

### Forbidden technical terms

| Forbidden | Use instead |
|---|---|
| fragrance load | Seberapa Kuat Aromanya? |
| concentrate ratio | Jumlah Aroma |
| alcohol ratio | — (omit entirely) |
| perfume concentration | — (omit entirely) |
| formulation percentage | — (omit entirely) |
| sillage | Jarak Wangi |
| longevity | Tahan Lama / Berapa Lama Wanginya? |
| top notes / heart notes / base notes | Aroma pembuka / aroma utama / aroma dasar (only if explaining; otherwise keep it simple) |
| Eau de Parfum / Eau de Toilette / Parfum | Parfum (use the generic term unless comparing) |

**General language rules:**
- Sentences under 15 words when possible
- One idea per sentence
- Active voice: "Kamu pilih aromanya" not "Aroma dapat dipilih oleh kamu"
- Numbers in rupiah format: Rp29.000 (no space after Rp, dot separator)
- No exclamation marks in more than 1 out of every 10 lines of copy
- No ALL-CAPS except for the ATLASE wordmark

## 2. Tone Principles

Drawn from the brand voice in branding.md, applied to copy:

| Principle | What it means in practice |
|---|---|
| Confident | State facts directly. "Parfum ini tahan 6 jam." not "Parfum ini InsyaAllah bisa tahan sampai 6 jam loh!" |
| Warm | Use "kamu" (not "Anda" for most surfaces). Acknowledge the reader. |
| Simple | If a 12-year-old wouldn't understand it, rewrite it. |
| Premium | Let the design and product quality speak. Copy doesn't need to SAY "premium" — it needs to FEEL premium. |
| Not too youthful | No "bestie", "slay", "autowishlist", "gacor". This isn't a TikTok comment section. |
| Not too formal | No "Silakan memilih", "Kami mengundang", "Adapun kami menyediakan". Speak naturally. |

**Tone calibration examples:**

| Situation | Too casual | Just right | Too formal |
|---|---|---|---|
| Welcome message | "Hai guys! Welcome!" | "Selamat datang di ATLASE." | "Selamat datang di website resmi ATLASE." |
| Product description | "Wanginya amazing banget!" | "Aroma yang elegan dan tahan lama." | "Kami hadirkan wewangian dengan profil aroma yang elegan dan ketahanan optimal." |
| Call to action | "Yuk buruan beli!" | "Pilih Aroma" | "Silakan melakukan pemilihan aroma" |
| Price display | "Cuma 29 ribu aja!" | "Mulai dari Rp29.000" | "Dengan harga mulai dari dua puluh sembilan ribu rupiah" |

## 3. Approved CTA Vocabulary

Use ONLY these CTAs across all surfaces. Do not invent new ones.

| CTA | Usage context |
|---|---|
| Pilih Aroma | Main product selection — homepage, catalog, product cards |
| Buat Parfum Ini | Product detail page — customize and order |
| Pesan via WhatsApp | WhatsApp ordering flow entry point |
| Lanjut Pesan | Mid-flow CTA in WhatsApp order process |
| Bayar dengan QRIS | Payment step — QRIS as primary payment method |
| Mulai dari Rp29.000 | Price anchor on product cards, ads, landing pages |
| Atur sendiri | Customization feature — strength, size, notes |
| Cari Aroma | Search/browse entry point — empty states, nav |

**CTA rules:**
- Maximum 2 CTAs per viewport
- Primary CTA uses Emerald (`#19A974`) button style
- Secondary CTA uses outlined or text-only style
- Never stack more than 2 CTAs vertically
- Never use "Klik Disini", "Selengkapnya", "Lihat Detail", or "Beli Sekarang"

## 4. Phrase Bank

### Approved phrases — use freely

| Phrase | When to use |
|---|---|
| Mulai dari Rp29.000 | Product cards, ads, hero sections |
| Pilih aroma favoritmu | Homepage, catalog, search results |
| Atur sendiri wanginya | Customization section, product detail |
| Sesuaikan dengan budget kamu | Price section, FAQ, comparison content |
| Pesan lewat WhatsApp | Order flow, footer, contact surfaces |
| Bayar dengan QRIS | Payment section, checkout |
| Wangi Mewah. Harga Bersahabat. | Ad copy, social captions, email subjects |
| Parfum Premium, Sesuai Kamu. | Hero subline, product pages |
| Premium, Made Personal. | Brand identity, packaging, social bio |
| Cocok untuk sehari-hari / Cocok untuk malam | Product descriptions |
| Tahan lama seharian | Product descriptions, FAQ |
| Dikemas rapi, siap kirim | Checkout confirmation, shipping info |

### Forbidden phrases — never use

| Phrase | Why |
|---|---|
| Luxury | Overused, loses meaning, feels pretentious |
| Premium (in body copy) | Save for tagline only — the word loses power when overused |
| Exclusive | Implies gatekeeping; ATLASE is accessible |
| Bespoke | Too technical, too English-heavy for the target audience |
| High-end | Marketplace language, not brand language |
| Kualitas terbaik se-Indonesia | Aggressive, unbelievable |
| Dijamin puas | Aggressive, marketplace-grade |
| Best seller / Paling laris | Feels like Shopee; avoid marketplace tropes |
| Diskon / Sale / Promo besar-besaran | Undermines the premium perception; "Mulai dari Rp29.000" is the price strategy |
| COD available | Not part of the payment flow; stick to QRIS and WhatsApp |

## 5. Section Copy Examples

### Hero Section

```
Headline:    Wangi yang Kamu, Harganya Masuk Akal.
Subline:     Parfum Premium, Sesuai Kamu.
CTA:         Pilih Aroma
Price hook:  Mulai dari Rp29.000
```

### Product Card

```
Name:        [Nama Parfum — e.g. "Noir Amanzi"]
Descriptor:  Dior-inspired · Aroma elegan · Cocok untuk malam
Price:       Mulai dari Rp29.000
CTA:         Buat Parfum Ini
```

**Variations:**
```
Dior-inspired · Aroma elegan · Cocok untuk malam · Mulai Rp29.000
Jo Malone-inspired · Aroma segar · Cocok untuk sehari-hari · Mulai Rp29.000
Tom Ford-inspired · Aroma smoky · Cocok untuk kencan · Mulai Rp29.000
```

### How It Works

```
Section title:  Cara Pesannya Gampang.

Step 1:  Pilih aroma favoritmu
         Cari yang cocok dari koleksi kami.

Step 2:  Atur sendiri wanginya
         Pilih ukuran dan seberapa kuat aromanya.

Step 3:  Pesan lewat WhatsApp
         Tinggal klik, kirim, dan tunggu dikirim.

Step 4:  Bayar dengan QRIS
         Praktis, langsung jadi.
```

### Customization Section

```
Section title:  Sesuaikan dengan Kamu.

Size options:   Kecil (10ml) · Sedang (30ml) · Besar (50ml)
Strength:       Ringan · Sedang · Kuat
Label:          Tulis nama atau pesan khusus di botol (opsional)
```

## 6. FAQ Copy

All answers in simple Bahasa Indonesia. No jargon.

---

**Q: Berapa harga parfumnya?**
A: Mulai dari Rp29.000. Harga tergantung ukuran dan jumlah aromanya. Semua opsi harganya sudah terlihat saat kamu pilih parfum.

---

**Q: Bisa pilih ukuran?**
A: Bisa. Ada tiga ukuran: Kecil (10ml), Sedang (30ml), dan Besar (50ml). Tinggal pilih yang paling cocok.

---

**Q: Bisa menentukan kekuatan aroma?**
A: Bisa. Kamu bisa pilih sendiri — ringan, sedang, atau kuat. Tinggal atur saat pemesanan.

---

**Q: Bisa pesan lewat WhatsApp?**
A: Bisa. Setelah pilih parfum, klik "Pesan via WhatsApp" dan ikuti langkah-langkahnya. Tim kami akan bantu prosesnya.

---

**Q: Bisa bayar dengan QRIS?**
A: Bisa. QRIS adalah metode pembayaran utama kami. Tinggal scan, bayar, dan selesai.

---

**Q: Berapa lama proses pembuatan?**
A: Parfum dibuat setelah kamu pesan. Prosesnya sekitar 1–3 hari kerja, lalu langsung dikirim.

---

**Q: Apakah bisa request botol?**
A: Untuk saat ini, botol mengikuti standar packaging ATLASE. Tapi kamu bisa tulis nama atau pesan khusus di label botol.

---

**Q: Apakah bisa pesan untuk hadiah?**
A: Bisa. Saat pemesanan, tulis di catatan bahwa ini untuk hadiah. Kami akan bantu kemas dengan rapi.

## 7. Error / Empty / Loading Copy

All system messages in simple Bahasa Indonesia. Clear, helpful, never blaming.

### Error states

| Scenario | Copy |
|---|---|
| Payment failed | Pembayaran belum berhasil. Silakan coba lagi. |
| Page not found | Halaman ini tidak ditemukan. Mungkin sudah dipindahkan. |
| Network error | Koneksi terganggu. Coba periksa internet kamu, lalu muat ulang. |
| Order failed | Pesanan belum terkirim. Silakan coba lagi atau pesan via WhatsApp. |
| Form validation | Isi kolom yang masih kosong, lalu coba lagi. |

### Empty states

| Scenario | Copy | CTA |
|---|---|---|
| Empty cart | Belum ada parfum di keranjangmu. | Cari Aroma |
| Empty search | Tidak ada yang cocok dengan pencarianmu. Coba kata kunci lain. | Cari Aroma |
| Empty order history | Belum ada riwayat pesanan. | Pilih Aroma |
| Empty wishlist | Belum ada parfum favorit. | Cari Aroma |

### Loading states

| Scenario | Copy |
|---|---|
| Page loading | Sebentar, sedang dimuat... |
| Cart updating | Memperbarui keranjang... |
| Order processing | Pesanan sedang diproses... |
| Payment verifying | Memverifikasi pembayaran... |

### Success states

| Scenario | Copy | CTA |
|---|---|---|
| Order placed | Pesanan kamu sudah diterima! | — |
| Payment confirmed | Pembayaran berhasil. Parfum segera dibuat. | — |
| Item added to cart | Ditambahkan ke keranjang. | Lanjut Belanja |
| WhatsApp order started | Chat sudah terbuka. Kirim pesananmu ke tim kami. | — |
