# ATLASE — Brand Guidelines

## 1. Brand Identity

**Name:** ATLASE

**Taglines:**

| Context | Language | Tagline |
|---|---|---|
| Brand identity (logo lockup, social bio, packaging) | English | Premium, Made Personal. |
| Website hero subline, product descriptions, ad copy | Bahasa Indonesia | Parfum Premium, Sesuai Kamu. |
| Commercial hook (ads, promos, landing page subheads) | Bahasa Indonesia | Wangi Mewah. Harga Bersahabat. |

**Visual Direction:**
Dark canvas with restrained color. The design should feel like a premium fragrance counter — not a marketplace listing. Photography carries the emotion; layout carries the confidence. White space is generous, type is sharp, and color appears only where it must.

**Brand Personality:**
Confident without being loud. Warm without being casual. Premium without being pretentious. ATLASE speaks like a well-dressed friend who genuinely wants you to smell good — not like a luxury brand talking down to you.

## 2. Brand Voice

**Core traits:** Confident · Warm · Modern · Simple · Premium · Not pretentious

**What the voice sounds like:**
- A friend who knows perfume and shares it naturally
- Straightforward, no jargon, no filler
- Polished but approachable — never stiff, never slangy

**Voice spectrum:**

| Too cheap ← | Sweet spot | → Too formal |
|---|---|---|
| "Murah banget nih bestie!" | "Wanginya enak, harganya masuk akal." | "Kami mengundang Anda untuk mengeksplorasi koleksi kami." |

**Avoid at all costs:**

| Avoid | Why |
|---|---|
| Corporate / technical tone | Feels distant, not warm |
| Overly casual / Gen-Z slang | Feels cheap, undermines premium perception |
| Aggressive sales language | "SEKARANG JUGA!" / "GAK TERMAKAN!" feels marketplace-grade |
| Too formal / Bahasa baku | "Silakan memilih" reads stiff; "Pilih" is better |
| Luxury buzzwords (overuse) | Repeated "Exclusive" / "Bespoke" / "Luxury" loses meaning |

## 3. Logo Usage

**Preferred logo type:** Typography-driven wordmark. The ATLASE name IS the logo — no icon mark required.

**Typography:**
- Wordmark uses a clean serif or geometric sans-serif with generous letter-spacing
- All-caps: `ATLASE`
- Weight: Medium or Semi-bold — never Thin (too weak) or Black (too heavy)

**Clearspace:**
- Minimum clearspace around the wordmark: height of the letter `A` on all four sides
- Never crowd the logo with adjacent text, badges, or decorative elements

**Scaling:**
- Minimum digital size: 80px wide
- Minimum print size: 20mm wide

**Do / Don't:**

| Do | Don't |
|---|---|
| Use the wordmark on dark backgrounds | Place on busy photographic backgrounds without a dark overlay |
| Keep clearspace clean and generous | Crowd with icons, badges, or additional text |
| Use approved color versions (white on dark, dark on light) | Recolor with arbitrary brand palette colors |
| Align to grid with consistent margins | Rotate, stretch, or apply effects (drop shadow, glow) |
| Use the lockup version (wordmark + tagline) when tagline is needed | Add a tagline that isn't part of the approved set |

## 4. Color Usage

**Brand palette:**

| Name | Hex | Role |
|---|---|---|
| Black | `#0A0A0A` | Primary background, primary text on light surfaces |
| Ivory | `#F5F2EA` | Light background, card surfaces, body text on dark |
| Deep Green | `#0D6B4D` | Secondary accent, hover states, subtle depth |
| Emerald | `#19A974` | Primary accent — CTAs, highlights, active states |
| Muted Gray | `#9A9A93` | Secondary text, borders, disabled states |

**Proportion rule:**
- Black + Ivory dominate: 80–90% of any screen
- Emerald appears sparingly: 5–10% — one accent element per viewport maximum
- Deep Green for supporting depth (borders, subtle backgrounds): 5%
- Muted Gray for tertiary information only

**Contrast & accessibility:**
- White/Ivory text on `#0A0A0A` — passes WCAG AA (contrast ratio ~18:1)
- `#19A974` (Emerald) on `#0A0A0A` — passes WCAG AA for large text; use at 16px+ for body
- `#9A9A93` (Muted Gray) on `#0A0A0A` — use only for non-essential text (timestamps, secondary labels); avoid for body copy
- Never place Emerald text on Ivory background (low contrast for small text)

**Usage rules:**
- Backgrounds alternate between Black and Ivory — never use Emerald or Deep Green as full-page backgrounds
- CTA buttons: Emerald background with Black text (high contrast, draws the eye)
- Hover states on Emerald buttons: shift to Deep Green
- Product cards: Ivory background with Black text, Emerald price highlight
- Section dividers: thin Deep Green line or simply space

**Never:** Green-everywhere. Emerald is a spotlight, not a flood.

## 5. Imagery Style

**Photography direction:**

| Attribute | Guideline |
|---|---|
| Background | Dark (`#0A0A0A` or near-black) — never bright white |
| Lighting | Soft, directional — single key light from upper left or right |
| Surface | Subtle reflection beneath the bottle (wet-look surface or glass) |
| Subject | The perfume bottle is the hero — centered or rule-of-thirds |
| Styling | Minimal props — if any, a single leaf, stone, or fabric fold |
| Color treatment | Desaturated overall with the bottle label as the only color pop |
| Composition | Generous negative space around the bottle |
| Human presence | Rarely — if shown, hands holding the bottle, never full-face lifestyle |

**Editorial style:**
- Think fragrance counter, not Instagram flat-lay
- Every image should feel like it could be a print ad
- Avoid busy collages, patterned backgrounds, or decorative frames
- If using text overlay, keep it to one short line — the image does the heavy lifting

**Consistency check:**
- Before publishing any image, ask: "Does this look like it belongs on a premium brand's website?" If the answer is no, restyle or remove it.

## 7. Do / Don't Brand Table

| Do | Don't |
|---|---|
| Use dark backgrounds for product imagery | Use bright white or pastel backgrounds |
| Keep layouts spacious with generous padding | Cram elements together to "fit more" |
| Use Emerald as a single accent per viewport | Paint entire sections green |
| Write in simple, warm Bahasa Indonesia | Use perfume jargon or corporate Bahasa baku |
| Show the bottle as the hero of every product image | Use lifestyle imagery that overshadows the product |
| Let the design feel premium through restraint | Add gold foil textures, ornate borders, or sparkle effects to signal "luxury" |
| Use "Premium, Made Personal." for brand identity | Overuse the word "premium" in body copy |
| Price with "Mulai dari Rp29.000" framing | Hide pricing or use "Call for price" |
| Keep CTAs clear and action-oriented ("Pilih Aroma") | Use vague CTAs ("Klik Disini", "Selengkapnya") |
| Maintain one accent color per screen section | Mix multiple accent colors in one section |
| Let typography carry the brand (wordmark IS the logo) | Add decorative icons or symbols around the logo |
| Write copy that a first-time perfume buyer understands | Write copy that assumes the reader knows fragrance terminology |
